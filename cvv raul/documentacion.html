Integración de Bootstrap

Para utilizar Bootstrap agregamos la línea de estilos dentro del head donde se encuentra la configuración principal de la página luego agregamos el script de JavaScript antes de cerrar el /body.

Bootstrap CSS 

<link
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
    rel="stylesheet"
>

Al agregar la linea de arriba podemos utilizar diferentes estilos de ccs sin tener que programar desde cero como container, row, card, badge y btn.

Bootstrap JavaScript 

<script
    src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"
></script>

El archivo JavaScript permite funcionar con css para darle animacion o el funcionamiento a nuestra pagina web para que tenga moviento o interacciones.

Componentes de Bootstrap

Botón

Utilizo los botones para acciones importantes como consultar un proyecto o enviar informacion.

Consultar proyecto 
<a
    href="#formulario"
    class="btn btn-primary"
>
    Consultar proyecto
</a>

En mi pagina utilice btn junto con btn-primary. Entendi que btn es la clase principal del botón y btn-primary define su variante.

Tarjeta

Las tarjetas me sirven para separar y organizar cada uno de mis proyectos de forma separada.

Dead Orden - Juego 3D

Videojuego desarrollado en Unity utilizando C#.

Consultar proyecto 
<article class="card">

    <div class="card-body">

        <h3 class="card-title">
            Dead Orden - Juego 3D
        </h3>

        <p class="card-text">
            Videojuego desarrollado en Unity.
        </p>

    </div>

</article>

Utilice card para crear la tarjeta para luego con card_body crear el area del contenido, luego card-title para el titulo del proyecto y card-text para dar el formato del texto luego replique lo mismo para los tres proyectos con una estructura siomilar.

Barra de navegacion

La barra de navegación conecta las tres páginas de mi sitio y cambia a un menú hamburguesa cuando la pantalla es pequeña.

<button
    class="navbar-toggler"
    type="button"
    data-bs-toggle="collapse"
    data-bs-target="#menuDemo"
>

    <span class="navbar-toggler-icon"></span>

</button>

<div
    class="collapse navbar-collapse"
    id="menuDemo"
>

    Menú

</div>

Aprendí que data-bs-target debe coincidir con el id del elemento collapse. Si son diferentes, el botón hamburguesa aparece pero no abre el menú.

Formulario

Bootstrap permite dar formato a los controles utilizando clases como form-label, form-control y form-select. 

<label
    for="nombre"
    class="form-label"
>
    Nombre
</label>

<input
    type="text"
    class="form-control"
    id="nombre"
    name="nombre"
    required
>

Utilicé form-label para las etiquetas y form-control para los campos. Bootstrap cambia su apariencia, pero required y type siguen realizando la validación del navegador.

Errores y silencios

Estos son algunos errores que pueden ocurrir sin mostrar un mensaje directamente en la página. DevTools ayuda a encontrarlos.

CDN mal copiado

Síntoma: la página aparece sin los estilos de Bootstrap.

Diagnóstico: abro DevTools y reviso Network. Si el archivo de Bootstrap no carga correctamente, puedo revisar la URL del CDN.

data-bs-target no coincide con el id

Síntoma: el botón hamburguesa aparece, pero al presionarlo el menú no se abre.

Diagnóstico: reviso el HTML en DevTools y comparo el valor de data-bs-target con el id del elemento que tiene la clase collapse. 

data-bs-target="#menuPrincipal"

id="menuPrincipal"

Bundle de JavaScript ausente

Síntoma: los estilos funcionan, pero componentes interactivos como el botón hamburguesa no responden.

Diagnóstico: reviso Network en DevTools para comprobar que bootstrap.bundle.min.js aparece y se carga correctamente.
